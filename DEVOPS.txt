KUBERNETES:-

Kubernetes is an open source container management tool , it automates deploying ,scalling and managing containerized application .
Kubernetes also called as K8S 


1. Docker
Purpose: Docker is a containerization platform. It packages an application and its dependencies into a container, ensuring it runs consistently across environments.
How it Works:
You define the application and its dependencies in a Dockerfile.
Docker creates an image from the Dockerfile.
Containers are instances of the image, running the application in an isolated environment.
Key Features:
Portability: Containers can run on any system with Docker installed.
Isolation: Each container runs independently.
Efficiency: Containers share the host OS kernel, reducing overhead compared to virtual machines.

2. Kubernetes
Purpose: Kubernetes is an orchestration tool for managing containerized applications at scale. It automates deployment, scaling, and management of containers.
How it Works:
Applications are deployed as pods, which are the smallest deployable units in Kubernetes.
Kubernetes manages pods using controllers like Deployments, StatefulSets, etc.
Features like load balancing, auto-scaling, and rolling updates are built-in.
Key Features:
Scalability: Automatically scales applications based on demand.
High Availability: Ensures applications stay up and running.
Self-Healing: Restarts failed containers and replaces unresponsive pods.


3. Jenkins
Purpose: Jenkins is a CI/CD (Continuous Integration/Continuous Delivery) tool. It automates the process of building, testing, and deploying applications.
How it Works:
Jenkins uses pipelines (defined as code) to automate workflows.
Triggers (like code commits) initiate builds.
Jenkins integrates with tools like Docker and Kubernetes to deploy applications.
Key Features:
Automation: Builds, tests, and deploys code automatically.
Extensibility: Supports plugins for various tools and technologies.
Integration: Works seamlessly with Docker, Kubernetes, Git, and more.
